# 威胁模型

本文档只描述公开、可复用的安全边界，不包含部署地址、真实身份、基础设施拓扑或私有系统信息。

## 保护目标

- 用户身份及不同消息通道之间的绑定关系；
- 日程、任务、备忘录、提醒及其元数据；
- 出站消息的目标、正文、幂等键和投递状态；
- 高敏秘密的存在性、访问策略和审计记录；
- 管理操作、授权结果及不可抵赖的安全审计。

## 信任边界

```text
外部消息平台
  → 通道适配器（验签、身份映射、限流）
  → 应用服务（命令/查询、确认、授权）
  → 领域核心（确定性规则）
  → 普通数据存储（仅 L0–L2）

可选 LLM
  → 只能生成受限提议
  → 必须重新经过确定性校验和授权

高敏保险库
  → 独立进程、独立账户、独立密钥和最小接口
  → 不允许 LLM 或通道适配器直接访问
```

普通应用存储拒绝 L3/L4 数据。保险库功能未完成或未解锁时，系统必须拒绝相关请求，不得退化为
明文存储。

## 主要威胁与控制

| 威胁 | 默认控制 |
| --- | --- |
| 伪造平台回调或重放消息 | 适配器验签、时间窗、nonce/事件幂等键 |
| 跨用户或跨通道身份混淆 | 外部标识进入存储前加密；使用内部用户 ID 和显式绑定 |
| 越权读写 | 默认拒绝；每次操作校验所有者、ACL、数据等级、通道和认证强度 |
| 并发覆盖或重复执行 | 乐观版本、唯一幂等键、事务内状态变更与 outbox |
| 群聊泄露私人内容 | L2 禁止群聊输出；敏感查询要求增强认证 |
| 提示注入或模型越权 | LLM 无数据库、消息发送、命令执行和保险库能力；输出仅作为提议 |
| 出站消息丢失或重复 | 持久化 outbox、租约、重试退避、死信和服务端幂等 |
| 日志或错误泄密 | 结构化脱敏日志；禁止记录正文、凭据、外部原始标识和秘密 |
| 依赖或提交供应链污染 | 本地发布门禁、依赖审计、秘密扫描、隐私边界扫描 |
| 管理员或主机权限滥用 | 最小 OS 权限、服务账户隔离、审计；部署细节不进入公开仓库 |

## 安全不变量

- 未通过 `PolicyEngine` 的写操作不得进入 repository。
- L3/L4 不得进入普通数据库、全文索引、日志、消息队列或 LLM prompt。
- 所有副作用必须先形成确定性、可审计的操作，再由受限适配器执行。
- 删除、秘密读取和其他高风险操作必须显式确认；高敏操作还需增强认证。
- 任何依赖、密钥或外部服务缺失时保持 fail-closed。

## 隐私测试要求

- 只使用合成身份、无效凭据和保留域名。
- 测试不得访问真实平台、真实服务器或开发者个人目录。
- 提交前扫描跟踪文件中的凭据形态、私有路径、地址和二进制数据。
- 安全缺陷按 [安全策略](../../SECURITY.md) 私下报告，不在公开 Issue 披露。

高敏秘密边界的细化模型见 [保险库威胁模型](VAULT_THREAT_MODEL.md)。
